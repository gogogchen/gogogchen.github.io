地球是我家——認識香港水資源（Prompt）

認識與「水資源聊天機器人」（人工智能） 互動的方法

  1. 「哪一個是全港面積最大的水塘？ 」

  2. 「哪一個是全港容量最大的水塘？」

  3. 理解爲什麽「全港面積最大的水塘」不是「全港容量最大的水塘」 ？

  4. 「水在日常生活中有哪些用途？」

  5. 日常生活中，水有哪些用途？試從你日常生活的經歷，舉出兩個例子。

  6. 地球被水覆蓋的面積(%)？其中的海水佔(%)？主要可以從哪裡取得？

  7. 地球上所有的淡水資源是否都可以直接使用？爲什麽？

水循環

  1. 水循環過程中步驟 1是什麼？

  2. 水循環過程中步驟 2是什麼？

  3. 水循環過程中步驟 3是什麼？

  4. 水會透過循環會回到海水和河流，那還有會淡水不足的問題嗎？

    例如：我覺得有了水循環，就不會有淡水不足的問題。

運用「水資源聊天機器人」進行深入探討：香港的水資源

  1. 什麽是東江水？

  2. 什麽是海水化淡？

  3. 香港本地的水源有哪些（不包括東江水）？

  4. 香港每年從本地集水量（包括地表水庫、地下水和雨水收集系統）有多少？

  5. 這些本地的水資源（不包括東江水）足夠市民日常生活嗎？

  6. 如果沒有足夠的水，會發生什麽事？請舉例香港的歷史事件，如制水。

  7. 制水期間，香港市民的生活是怎樣的？

  8. 東江水（東深供水工程）的目的是什麼？它對香港有甚麼影響？

思考、反思與創意：香港與新加坡的不同之處

  1. 如果沒有東江水供應，對香港人的生活會有甚麼挑戰？ （環境、公共衛生、經濟、及社會穩定等關係到國家安全層面。）

  2. 就有關水資源短缺問題的挑戰和解決方案，以表格形式列出香港和新加坡在水資源上的不同之處，並作出比較。

  3. 新加坡政府是如何運用先進技術，引進多元化水源來開發水資源？

  4. 儘管香港和新加坡兩地都有外部水源，爲什麽新加坡如此重視使用高科技發展新生水和海水淡等水處理技術？

  5. 作為香港市民，我們可以如何為應對未來可能出現的水資源短缺挑戰貢獻一份力量呢？

  6. 如何設計一張感謝卡，來表達感謝國家為我們提供珍貴的水資源。

認識香港的歷史——「抗日戰爭」（Prompt）

第一教節：抗日戰爭與香港淪陷

  1. 我們為什麼需要紀念抗日英勇烈士？

  2. 香港沙頭角抗戰紀念館、烏蛟騰

  3. 「12 月 25 日本應是快樂的聖誕節，為什麼香港人稱之為『黑色聖誕』？」

第二教節：日佔時期的香港

  1. 1941年至1945年香港人口劇降，導致當時人口大幅減少的原因有哪些？

  2. 「東江縱隊」是什麼組織？

  3. 東江縱隊港九獨立大隊在郊區的抗日活動有哪些？

  4. 東江縱隊港九獨立大隊的抗日活動有什麽重要意義？

  5. 你認為中國人民在「抗日戰爭」取得勝利最重要的原因是什麼？

第三教節：歷史迴響之珍惜和平

  1. 這些抗戰遺址（例如：沙田觀音山村）今天仍然存在，為了紀念誰？有什麽目的？

  2. 如果你是參觀抗戰遺址的學生，需要寫/畫一張留言卡，你會寫/畫什麽？（我可以畫兩隻麻雀嗎？）

  3. 對於東江縱隊港九獨立大隊及無數參與抗日戰爭的市民，我們可以傳承他們身上什麽優點？

  4. 想像你是當時的一位普通市民，面對戰爭你會如何保護家人和社區？

  5. 中國現時強調與其他國家建立和平關係，你覺得從抗日戰爭的歷史中可以學到哪些教訓，來幫助維持和平？

第四教節：歷史迴響・聲音傳承——播客說和平

  1. 「香港保衛戰」的歷史與「和平的意義」

  2. 我們三人小組要錄製播客，講述「香港保衛戰」和我們從中學到的和平的重要性，幫我們把剛剛整理的內容分成「開場 → 主體 → 結尾」的形式，分配旁白内容。在每個段落旁註明錄製時的語氣，例如「這裡要帶出什麼感受」。
